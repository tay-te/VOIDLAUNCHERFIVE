# `hearth/` — VOID Hearth

Living settlements for **Minecraft 26.3** (Fabric): folk with homes, trades and routines who build and grow their towns
while you play — and while you are away — coin struck at settlement mints, and quests that come from what a town needs.
A companion to VOID Expanse and VOID LOD.

```
Fabric Loader ≥ 0.19.5 · Fabric API 0.161.0+26.3 · Java 25 · optional: VOID Expanse, VOID LOD
```

Work in progress. The design and the module contract are in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Build

```sh
cd hearth
./gradlew build          # → build/libs/void-hearth-<version>.jar
```
