# `mettle/` — VOID Mettle

Who you become in the VOID world, for **Minecraft 26.3** (Fabric): a background you start from, five attributes, skills
that grow by doing them, perk trees that change how you play, and an honest inventory where everything weighs, with a
backpack, belt and quiver worn on the character. A companion to VOID Expanse, VOID LOD and VOID Hearth.

```
Fabric Loader ≥ 0.19.5 · Fabric API 0.161.0+26.3 · Java 25 · optional: VOID Hearth, VOID Expanse
```

Phase 0 (design). Nothing is built yet. Start with [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (the contract between
modules), then the design docs it links.
