A 60px rail of small icon buttons, a list of every instance always visible beside it, and a working canvas on the right. Switching instances never leaves the page — you click a row and the canvas swaps. This is the layout that scales to forty instances.

The system underneath

Every value below is a token that already exists in src/renderer/styles/. Adopting this look is editing scale.css and adding one theme file — the component markup only changes where a layout changes.

FontManrope, embedded as a data URI. Worth knowing: ui-rounded and SF Pro Rounded both fall back to Times in Chromium, and macOS blocks .SF NS Rounded from web content — so there is no system route to a rounded face in Electron. One 24KB variable woff2 covers weights 200–800.

What I'd ship

Layout A as the app, layout C's transport bar grafted onto it. A gives you the permanent instance list that makes forty packs manageable; C's bottom bar fixes the thing that's actually broken today — launching currently pins you to one page, and it shouldn't.

Layout B is the one to build if VOID is going to have cover art per pack. It's the best-looking of the three by some distance, but without artwork it's gradients derived from an icon colour, and that ceiling is low.

The rounded type and the raised radius are independent of all three — a scale.css edit, one theme file, and dropping manrope-latin.woff2 (24KB) into the bundle. Roughly an afternoon, and it can land before any layout work starts.

One caveat worth carrying forward: the font has to be bundled. There is no system rounded face Chromium will render, so ui-rounded in a stylesheet silently gives you Times — which is exactly what this page did before the font was embedded.
