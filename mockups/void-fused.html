The toggle names the task, not the user

Simple / Advanced told anyone who stayed put that they were on the training-wheels build. Play / Manage describes what you are doing instead — and nobody feels demoted for launching a game with a launcher.

Managing pauses the automation

The two modes were quietly fighting: Play updates mods on its own while Manage lets you pin versions by hand. Entering Manage now pauses automatic changes for that pack and says so, with Resume.

This was the toggle’s real hole. Without it, VOID would silently overwrite a power user’s work.

The toggle is not the only door

Manage 342 mods on the stage deep-links straight to that table, pulses it, and shows a Done that returns you to the exact page you left. Arriving via the toggle shows no Done — the toggle is already the way back.

And the modes map onto each other: Friends goes to Friends, not Library. Which meant building the Friends table that was missing.

One button scale

Join was 38px sitting beside 26px secondaries on the same row, which is what made the chrome look unresolved. There are now two heights and no others: 34px for anything on a hero action row, 26px for dense toolbars and table rows.

Radius, gap, icon size, weight and padding are set once for every control, so a button cannot drift.

The roster tells you something

The friends strip dimmed offline people to near-invisible and told you nothing. It is now grouped — Online 3, a divider, Offline 11 — with online friends carrying a live dot and offline ones showing when they were last seen instead of fading out.

The spotlight is gone

Browse had two faces — a narrow centred search with a side preview, and the full list. The narrow one has been deleted outright, along with its collapse control and keyboard hints.

Browse is a list and only a list now, so Escape and the toggle no longer offer a state it does not have.

Clicking a result opens its page

The detail page is built from the app’s own parts, not a scrolling document. A 132px plate paired with the identity, exactly like the Play stage; compatibility as an inline pill beside the actions; then two columns — About and Versions on the left, a Details rail using the same key/value rows as the side panels elsewhere.

The five-box stat grid and the floating caps headings are gone. They existed nowhere else in the launcher.

Dependencies stay on-message — Iris reads “Sodium · required · VOID will add it for you” and Starlight reads “Radon · conflicts · VOID will swap it out”. An already-installed mod swaps its primary to Already in this pack.

Install still works from the list without opening anything, and Back or Escape returns you to the results.

Browse, reworked

The section-tab row duplicated the filter row, so it is gone. One toolbar now carries type, loader, version, category, sort and the install target. Rows gained a 44px plate, a meta line of downloads, recency and compatibility, and a Best match for this pack flag on the top result.

Mesh has a floor

Gradient-as-light and gradient-as-identity age well; gradient-as-decoration does not. Below 44px three radial stops plus grain stopped being artwork and became a coloured blob, so small plates are now flat — same hue, legible monogram, cheaper to paint.

Table rows, strip pills and dependency chips go flat at 24–40px. Result rows, the compressed header plate and every hero keep the mesh from 44px up, where it still reads as an image.

Dark is not an inversion

In light, the aurora is light falling on paper. Flipping the tokens would have produced muddy brown smears on black, so in dark it is re-authored as glow — hotter hues, higher blur, and a screen blend so the colour adds light instead of tinting a surface.

The grain switches from overlay to soft-light for the same reason, and plates get a touch more saturation so the artwork still reads on black.

The rest is just tokens

Every hardcoded colour was pulled into a variable first — hovers, shadows, veils, the primary’s hover. After that, dark is one block of values: warm charcoal ground #131210, panels a step lighter, hairlines as low-alpha white.

Because solid is keyed to the ink token, the one primary action inverts by itself: Launch becomes a light pill with dark text and stays the only filled thing on screen.

Nothing is pure white

Cards were #ffffff on an #ececeb ground, which is the harshest pairing available. Surfaces are now a warm #f6f6f3 over a slightly deeper #eaeae8, and every translucent fill went from rgba(255,255,255) to a warm veil.

Panels are translucent, so the aurora tints them rather than being blocked out by a white rectangle.

Outline first, one exception

The chrome is drawn, not filled. Chips, buttons, circular actions, selected tabs and checkboxes are all rings and ticks. Selection reads as a darker outline rather than a black block.

Launch is the only solid element on screen — verified at runtime, in both depths. Section primaries like Update 3 are drawn strongly instead, so they never compete with it.

Four ways back out

Collapse used to be small grey text at the far right — the last place anyone looks. Now the header carries a real Close button with its shortcut printed on it, the section row keeps a bordered Collapse, Escape works, and clicking the compressed subject closes it just as clicking the large one opened it.

The subject is a toggle in both directions, which is the only rule worth learning here.

Each tab opens at its natural depth

Play and Friends start focused — one pack, one person, one action. Browse starts open, because searching is inherently a list and a spotlight that hides its results is a worse spotlight.

Each tab then remembers the depth you left it at, so the app stops arguing with you.

The subject is the way in

You do not hunt for a control. Click the pack or the friend — the thing you are already looking at — and it opens. The plate lifts on hover, keyboard users get Enter and Space, and Edit pack exists for anyone who wants a button to aim at.

Browse: advanced, stripped

The faceted sidebar with four checkbox groups is gone. In its place, one row of filter pills — type, loader, version, category, sort, and the install target — over clean rows carrying plate, name, author, a one-line description, category, downloads and a single Install.

Everything the sidebar did, in a sixth of the chrome.

Nothing is replaced, only resized

A toggle swaps one screen for another, which is why the two always felt like two apps. Here the plate, the name and the Launch button are the same DOM elements at two sizes — they travel between states rather than being destroyed and rebuilt.

So the subject can never be lost on the way, because it never leaves.

The detail fills dead space

The stage always had an unused lower third. That is now exactly where the tables live, which means expanding costs you nothing you were using — the pack strip hides, the detail takes its place.

Section tabs replaced the sidebar: lighter, and they belong to the subject rather than to a mode.

The tabs never move

The two modes felt like two apps because the navigation itself changed — three tabs in Play, a nine-item sidebar in Manage, with nothing connecting them. A missing Friends entry was possible precisely because the two navigations were never reconciled.

Now Play / Browse / Friends live in the header in both modes. Mode changes density and depth inside a section, never where you are.

The sidebar became contextual

It is no longer a second global nav. On Play it lists the selected pack’s parts — Mods, Worlds, Versions, Java. On Browse it lists what you are searching for. On Friends it lists groupings.

One sentence to learn: tabs are where you are, the sidebar is what is inside it, mode is how much detail you want.

The subject comes with you

Pick Cobblemon Spring on the stage and switch: its plate and name head the sidebar, its row is selected in the table, Mods reads 84 not 342, and the pause banner names it. One function keeps every mention in step.

Manage also stopped dimming the aurora so hard — 40% rather than 20% — so the switch reads as the same room at a different focal length.

Advanced is a real workbench

Library is a sortable table with loader, MC version, mod count, size and update badges. Mods is the 342-row manager Simple could never hold — checkboxes, bulk Update 3 and Disable, per-row version history and removal.

Browse is deliberately Modrinth-shaped: a faceted filter rail with live counts, and full result cards with descriptions, categories, downloads and recency.

The AI is the simple mode

The search field became Ask VOID anything, and the command bar leads with real questions — “make this pack load faster”, “why is my game stuttering?” — above a Handled for you section.

The point is not a chatbot bolted on. It is that Simple mode has opinions, and Advanced mode is where you overrule them.

Every pack has a face now

Six studies flagged that letter badges were standing in for artwork. Rather than wait for an asset pipeline, each pack carries three colours and its plate is generated from them — mesh gradient, grain, monogram.

It ships today, works offline, and real Modrinth art can replace the gradient later without touching the layout.

The stage is a pair, not a column

A 76px headline centred in a 1300px window never used its width, and the lower third read as unfinished. The plate and the text are now one horizontal pair, centred as a group and left-aligned inside it.

Same focus — one subject, one action — but the composition finally has an anchor.

The light follows the pack

The aurora keeps its warm centre and picks up the selected pack’s hue at the edges, cross-fading over 420ms so it never snaps. Fear Nightfall turns the room violet; Cobblemon turns it blue.

The tint is deliberately weak. The pack should inflect the room, not repaint it.

Browse and Friends caught up

Both were running the old flat treatment. Mods now carry their own plates, the list leads with a top result that says why it won, and the preview is a product page — plate, description, a compatibility banner, three stats, tags, one install.

Friends uses the same plate made round, in the same paired composition as Play, and its band shows the actual cover of the pack they are in.

Compatibility became a sentence

Iris says “VOID will add Sodium for you” and Starlight says “Conflicts with Radon — VOID will swap it”, each with a different colour and icon from the plain green “works with your pack”.

Three states, one line, no dependency tree for the user to read.

Nothing on screen is a chore

The old Play page handed you work: 3 updates to click, a Java version to read, 12 in queue to mind. All three are gone. Updates apply themselves, Java installs itself, memory is set from the pack’s mod count.

What is left is a confirmation: “Updates applied this morning · 8 GB set aside · Java handled”.

Reported, not requested

Automation without a receipt is just software doing things behind your back. So the Handled while you were away moment lists every change in plain language, says why — “342 mods was too many for 4” — and offers Undo all.

That undo is the price of acting on someone’s behalf. Without it this design is arrogant.

Browse and Friends do it too

Iris no longer says “Requires: Sodium” like homework — it says Sodium — added automatically. And a friend playing a pack you do not own reads “VOID will install it for you”, with the time it takes.

Same promise, applied to the two places it is most often broken.

The command bar exists now

Three studies deferred to ⌘K without ever drawing it. Here it is — press K. It leads with what you are most likely to want, and carries a Handled for you section so automation is reviewable rather than hidden.

The strip’s +31 more pill opens the same surface, which is how a nine-pack strip survives forty packs.

Launching says less, not more

No log window, no mod-by-mod scroll. One bar, a percentage, an honest estimate, and the one fact that actually helps: you can close this window and the game still opens.

Where this gets hard

Every automatic decision must be right almost always, because the interface no longer gives you a way to see it coming — only a way to undo it afterwards. Memory sizing and mod-update compatibility are where that will break first.

And the first run makes a promise. If the second launch asks the user to fix a Forge version, the whole design has lied.
