Four ways to build VOID

The launcher currently wears the same neutral-grey-and-green dashboard as every other Electron app shipped this year. These are four home screens that don't. Same data, same components, four different opinions about what a Minecraft launcher should feel like.

Design study

Deep Field

Cinematic depth

Blue-black ground, a mint-to-iris gradient used as light rather than as a dot of neon, glass panels that actually stack. Closest to where you are now — the same tokens, pushed until they mean something.

Risk lowEffort 2 daysDark only
Blockwork

Voxel brutalism

Three-pixel black borders, hard offset shadows, no rounded corners anywhere, buttons that physically press down. The only direction that looks like it belongs to Minecraft and nothing else.

Risk highEffort 5 daysLight + dark
Console

Precision instrument

Hairline rules, monospace readouts, dense rows, and one rule held absolutely: colour appears only where it carries state. Everything decorative is greyscale. Built for people running 340-mod packs.

Risk mediumEffort 3 daysDark first
Field Manual

Printed reference

Cool paper, an old-style serif, ultramarine, and rules instead of cards. The launcher as a well-set technical book. Calm where the others are loud, and the only one that reads as premium in daylight.

Risk highEffort 4 daysLight only

How to read these

Every screen below is the same home page with the same data: Bittontayte, three instances, All The Mods 9 selected, Java 21.0.3, two friends on. Nothing is invented to flatter a direction — if a layout struggles with a 342-mod pack, you'll see it struggle here.

They also share one stylesheet. Each direction is a block of CSS custom properties plus a short override list, which is exactly how it would land in index.css — the structural markup never changes. That's the practical argument for picking two and shipping them as themes rather than picking one and rewriting components.

My recommendation: Console as the default and Field Manual as the light theme. Deep Field is the safe answer and will look like every other launcher in a year; Blockwork is the memorable answer but it will fight you on every dense screen — the Browse grid especially.

01 — Deep Field

Depth as the organising idea. The background is a lit space, not a flat colour; panels float in it with real blur and a hairline of light along their top edge. Accent is a mint-to-iris gradient, so it reads as illumination instead of a highlighter.

Where it wins
Screenshots. This is the one that sells the launcher on a store page or a Discord post.
Where it hurts
Backdrop blur on many panels costs real frames in Electron. And it's a crowded look — half the tools you use already do it.

02 — Blockwork

The game is made of cubes, so the interface is too. Three-pixel black outlines, hard shadows offset down-right with zero blur, a 16px block grid showing faintly through every surface, and a launch button that travels four pixels when you press it.

Where it wins
Identity. Nobody confuses this with a generic Electron app, and the physicality makes clicking things feel good.
Where it hurts
Density. Hard borders and offset shadows need air — the Browse grid and mod lists will each need a quieter variant.

03 — Console

Built for the person running a 342-mod pack who wants to know why it takes 90 seconds to load. Hairline rules, monospace readouts, tight rows, and one hard rule: colour appears only where it carries state. Everything decorative stays greyscale, so amber genuinely means look here.

Where it wins
Scales. Every dense screen you have — Browse, mod lists, instance detail — gets easier, not harder.
Where it hurts
Cold on first run. A new player sees a control panel, not a game. The onboarding screens need warmth added back deliberately.

04 — Field Manual

The launcher as a well-set reference book. Cool grey paper rather than the warm cream every AI-designed page reaches for, an old-style serif at real sizes, ultramarine for anything actionable, and rules doing the work cards used to do. Nothing floats; everything sits on the page.

Where it wins
Daylight and long sessions. It's genuinely restful, and it makes the app feel considered rather than gamer-default.
Where it hurts
Mod art. Modrinth icons are saturated and glossy — they'll look pasted onto this page unless every thumbnail gets a frame and a matte.
