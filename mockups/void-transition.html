Sodium

Sodium is a free and open-source rendering engine replacement for Minecraft which greatly improves frame rates and reduces micro-stutter, while fixing many graphical issues.

Not a drop-in replacement for OptiFine. It does not include shader support on its own — use Iris alongside it.

Why it is faster

The vanilla renderer rebuilds chunk meshes on the main thread and re-uploads more geometry than it needs to. Sodium rewrites that path rather than patching around it.

Multi-threaded chunk meshing— so world updates stop blocking the frame
Vertex format compression— cutting GPU memory use by roughly 40%
Smarter culling— geometry behind you is never submitted
Fixed translucency sorting— on water, ice and stained glass

Nothing cross-fades

Sheet content slides up into a clipped box rather than dissolving. Physical things are revealed or occluded — dissolving is what made the old version feel like a web page.

Leaving ≠ arriving

Departures accelerate out on cubic-bezier(.6,0,.9,.2). Arrivals decelerate in with a 4% overshoot and settle. Two different physics for two different jobs.

There is a beat of stillness

Query controls snap shut in 120ms, then nothing happens for 170ms, then the panel commits. Silence is what makes each move read as an event.

Rows collapse in sequence

13ms apart, top to bottom. Twelve rows collapsing in perfect unison was the single most mechanical-feeling mistake in the old build.

The press lands first

The row pushes down 1px on :active before any layout moves. Cause has to visibly precede effect or the whole thing feels like it happened to you.

The panel has mass

Cover, title and geometry share one delayed, overshooting curve, so the panel reads as a single heavy object arriving — not six properties animating.
